# Restro 🍽️

A modern responsive restaurant website built with React.js and Vite.

## 🚀 Live Demo

[View Live Website](https://restro-rouge.vercel.app/)

## 🛠️ Tech Stack

- React.js
- JavaScript
- Vite
- Tailwind CSS
- Framer Motion
- Lenis

## ✨ Features

- Responsive restaurant website
- Modern UI
- Smooth scrolling
- Animations
- Restaurant menu/dishes section
- Contact section
- Table booking UI


## 📂 Run Locally

```bash
npm install
npm run dev
